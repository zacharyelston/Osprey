# Buck hand-off: sar-offshore, blended wing body

Outer mould line of the sized design, in millimetres (x forward, y port, z up). The wing parts at its chord line into an upper and a lower mould; each buck is the solid above or below that line.

| | |
|---|---|
| Span | 1316 mm |
| Root / tip chord | 441 / 129 mm |
| Centre-body depth | 75 mm |
| Sweep (leading edge) | 36.5 deg |
| Wetted area / skin at 0.35 kg/m² | 0.56 m² / 0.20 kg |
| Volume inside the OML | 5.8 l |
| Stock for the upper buck (L x W x H, with 25 mm margin) | 667 x 1366 x 119 mm |
| Stock for the lower buck | 666 x 1366 x 104 mm |

Files: `oml.stl`, `buck_upper.stl`, `buck_lower.stl` (closed solids, binary STL), `sections.csv` (25 stations, upper and lower points).

Notes:
- The parting surface follows each section's chord line, so with washout it is gently twisted, not flat. Mount each buck on a parting board shaped to it.
- The bucks are the bare OML. Add flanges, draft and a release finish before taking moulds off them.
- Winglets, the payload fairing and the prop mount are separate parts and are not in these files.
