# Plug hand-off: escort-flanks, blended wing body

Outer mould line of the sized design, in millimetres (x forward, y port, z up). The wing parts at its chord line into an upper and a lower mould; each plug is the solid above or below that line.

| | |
|---|---|
| Span | 1147 mm |
| Root / tip chord | 441 / 132 mm |
| Centre-body depth | 75 mm |
| Sweep (leading edge) | 38.3 deg |
| Wetted area / skin at 0.35 kg/m² | 0.49 m² / 0.17 kg |
| Volume inside the OML | 4.9 l |
| Stock for the upper plug (L x W x H, with 25 mm margin) | 636 x 1197 x 119 mm |
| Stock for the lower plug | 636 x 1197 x 104 mm |

Files: `oml.stl`, `plug_upper.stl`, `plug_lower.stl` (closed solids, binary STL), `sections.csv` (25 stations, upper and lower points).

Notes:
- The parting surface follows each section's chord line, so with washout it is gently twisted, not flat. Mount each plug on a parting board shaped to it.
- The plugs are the bare OML. Add flanges, draft and a release finish before taking moulds off them.
- Winglets, the payload fairing and the prop mount are separate parts and are not in these files.
